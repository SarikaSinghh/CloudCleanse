FileUpload
------------------------------
	divide file content into blocks
	generate hash signatures for each block
		check weather hash signature exists in the database or not

			don't upload to cloud
			send success message
		else if not exists
			encrypt block contents with sec key
			upload encrypted block to cloud
			store hash signature in database
